# Stitch designs — Restaurant App

This directory holds the **approved** Google Stitch designs for the Restaurant App.

* Stitch is the **visual** source of truth (layout, spacing, typography, colors, components, states).
* The specifications are the **behavioral** source of truth.
* Designs are never fabricated. Only the project owner adds approved designs here.

## Layout

```text
design/stitch/
├── batch-01/
│   ├── 01-<screen-name>/
│   │   ├── screen.png          # exported screenshot(s)
│   │   ├── code/               # exported Stitch code (reference only)
│   │   └── notes.md            # optional: states, interactions, open questions
│   └── ...
└── batch-02/
```

Batch and screen numbering follow `../../SCREEN_PLAN.md`.

## Conflicts

If a design conflicts with a business, API or security rule: do not invent behavior — implement the rule, keep the design as close as possible, and report the conflict for a decision.
